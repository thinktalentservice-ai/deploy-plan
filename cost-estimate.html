ℹ️ Variant ④ (GCP Serverless + Cloudflare) takes GCP's serverless compute (Cloud Run, true scale-to-zero) but replaces the always-on GCP Global Load Balancer (~$18/mo base) with a Cloudflare Worker front door — which adds free WAF + DDoS and edge-caches responses, cutting both egress and backend wake-ups. Cheaper than pure GCP at low/medium traffic while keeping one hyperscaler for all compute.
✅ Pick guide: Lowest bill + fastest to ship → ② Vercel+Railway+CF. One hyperscaler with serverless economics + strong edge security → ④ GCP Serverless + CF. Single-vendor governance/compliance → ③ GCP. Azure-native stack or existing Microsoft EA → ⑤ Azure. Heavy sustained / deep VPC / regulated with a platform team → ① AWS (use Graviton + Spot + Savings Plans to cut cost).
⚠️ AWS figures assume Fargate. ECS on EC2 (t3a.2xlarge) all-Spot with dense bin-packing drops AWS compute ~70% (≈$414/mo medium) but adds the most ops — see platform-comparison.html for the EC2 deep-dive.

Omitting them from a proposal creates a budget surprise at go-live and erodes client trust. All figures are list-price estimates as of June 2026; mark items tagged [est] as estimates.

For 300 low-traffic services this covers most of the compute at Low traffic. The $35/mo Front Door Standard base is the dominant fixed cost — it bundles CDN, WAF managed rules, DDoS, and TLS offload.
